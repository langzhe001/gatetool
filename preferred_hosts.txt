# 手动优选 IP / 域名名单 —— pool 订阅的节点就按这个名单生成, 不再自动测速
# 用法: 在 GitHub 仓库网页上编辑/上传覆盖本文件, 一行一个, 然后手动运行一次
#       Actions 里的「CF Edge Pool Refresh」工作流即可生效。
# 格式 (端口不写默认 443):
#   1.2.3.4
#   1.2.3.4:8443
#   cf.example.com
#   cf.example.com:443
#   [2606:4700::1]:443
# 以 # 开头的行和空行会被忽略; 重复行自动去重; 顺序就是订阅里的节点顺序。
